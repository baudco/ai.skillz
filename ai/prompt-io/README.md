# AI Prompt I/O Log

This directory tracks prompts and outputs for AI-assisted development
across harnesses. New records live directly here; historical records
remain in their original harness subdirectories.

## Policy

Prompt logging follows the
[NLNet generative AI policy](https://nlnet.nl/foundation/policies/generativeAI/).
Substantive contributions record the original harness, known provider
and exact model, timestamps, prompting sequence, human contributions,
and an unedited `.raw.md` partner. Records never replace earlier output
or imply human acceptance of generated changes.

## Usage

The `/prompt-io` workflow creates paired records and may be invoked by
commit workflows. Human contributors remain accountable for code and
workflow decisions; generated work is not presented as human-authored.
